= A9 research archive: known broken coexistence

This branch preserves the experimental A9 monitor code separately from
codex/cdj3000x-streaming. Do not enable it for live track monitoring.

209 captured A9 state frames decoded successfully. Physical movements on
channels 3 and 4 were confirmed. The monitor used the TCS-SHOWKONTROL wire
identity with ShowKontrol closed. No mixer settings commands were sent.

The combined run stopped receiving fresh track status on both decks after
monitor registration. Cached titles and waveforms remained visible while
faders continued updating. Initial coexistence claims were incorrect.
A separate address/socket design has not been implemented or validated.
Player-number defence remains enabled. Crossfader/VU support is not validated.

The streaming-only branch removes these monitor hooks completely.
The research dependency has a distinct version to avoid accidental substitution:
8.1.0-imlach-a9-research-SNAPSHOT.

The tools/a9 launcher is retained as source evidence only. It depends on the
companion BLT TestLauncher and automatically starts the problematic handshake.
Do not run it in a show. Raw captures and vendor binaries are not distributed.

JDK 17 and Maven can compile the library using:

 mvn -Dmaven.javadoc.skip=true -Dgpg.skip=true verify
